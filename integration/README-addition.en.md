## Governed AI order exceptions (release candidate)

An additive reference extension introduces bounded read-only investigation, deterministic policy, independent approval and replay-safe sandbox effects. The model cannot approve or execute an action.

Start with [the governance guide](docs/governed-ai/en/overview.md), [integration instructions](docs/governed-ai/en/integration.md), and [verification limits](docs/governed-ai/en/testing.md).

The independent Java demo and English/German release assets are supplied as a separate release-candidate source package. The integration overlay is not a claim of completed stack acceptance or production readiness. Existing order APIs and the original out-of-stock branch are unchanged.
