## Project card

**Governed AI Workflow Platform**  
A Java 21 reference for AI-assisted order exceptions with bounded read tools, deterministic policy, independent human approval and replay-safe sandbox effects. Includes a bilingual review console, an Ollama adapter, failure tests and an additive Camunda/Spring integration candidate.

## CV bullet supported by this delivery

Developed a governed workflow reference separating model proposals from execution authority, with exact approval binding, tenant/role checks and durable sandbox receipts; verified recovery from a real worker crash and server restart without duplicating the effect.

## Evidence bullet

Published 106 passing Java contracts, 29 real HTTP/process tests, an explicitly scoped nine-check browser harness, and a 48-case bilingual baseline evaluation with per-case results and documented integration gates.
