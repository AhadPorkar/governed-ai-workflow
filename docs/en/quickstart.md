# Quickstart: independent source package

## Prerequisites

Install a **Java 21 JDK** (`java`, `javac`, and `jar` on PATH) and Python 3.10 or newer. No Maven, Docker, cloud account, paid model key or database is needed for the independent baseline demonstration. Linux was tested here; Windows launchers are supplied but Windows execution was not tested.

Run every command below from the extracted **source-package root**, not from the host BPMN repository. The host overlay has a separate integration procedure.

```bash
python scripts/run_demo.py
```

Open `http://127.0.0.1:8095`. The command builds the Java sources, creates local demo identities only when absent, and seeds two synthetic tenants without resetting existing orders.

The credentials are in `.local/access.json`. Paste the `operator` value into the console. Create a case for `ORD-1001` with `Please refund my unavailable order.` Select **Investigate**, inspect the proposal, then sign out. Sign in with the separate `reviewer` value, inspect the original request and exact amount, enter a reason, and approve.

In a second terminal:

```bash
python scripts/worker.py --once
```

Refresh the case. The receipt explicitly says `sandbox: true`. A viewer can inspect evidence but cannot create or approve. The `other` identity demonstrates a separate tenant.

## Tests and evaluation

```bash
python scripts/test.py --repository
python scripts/evaluate.py --no-build
```

The first command performs a clean build and runs Java contracts, real HTTP/process tests and repository checks. The evaluation is a separate labelled dataset experiment; mismatches are reported, not converted into passing unit tests.

To run native Chromium UI tests on your own machine:

```bash
python -m pip install -r requirements-browser.txt
python -m playwright install chromium
python scripts/test.py --browser --repository
```

Set `CHROMIUM_PATH` to a browser executable when needed. Without a usable system path, Playwright uses its installed Chromium. Native transport is the default. The special `GOV_UI_TRANSPORT=harness` mode exists only to disclose a restricted-environment DOM test; it must not be substituted for native acceptance without documenting that change.

## A real model is opt-in

Run a trusted local Ollama server and install a tool-capable model appropriate for your hardware and license. No particular model was evaluated in this delivery.

```bash
python scripts/run_demo.py --provider ollama --model YOUR_INSTALLED_MODEL
python scripts/evaluate.py --provider ollama --model YOUR_INSTALLED_MODEL
```

The default endpoint is `http://127.0.0.1:11434/api/chat`. Use `--model-endpoint` for the demo and `--endpoint` for evaluation. Remote endpoints require HTTPS. The URL is trusted administrator configuration, never a customer or model argument. Review data processing terms before sending anything other than synthetic data.

Provider errors escalate; they do not silently switch to the baseline. The baseline is visibly labelled and makes zero model calls.

## Credentials and retained state

Credentials expire after 24 hours. Stop the application, then rotate and restart explicitly:

```bash
python scripts/run_demo.py --rotate-credentials
```

Rotation preserves `.local/state`. Never commit `.local`, tokens, real requests or model credentials. To create a fresh disposable demonstration, use a new extracted directory rather than deleting an unfamiliar data directory. On Windows, review NTFS permissions because POSIX permission changes are not a substitute for Windows ACLs.

`build/governed-ai-demo.jar` is generated by the build; it is not a self-contained web bundle. Use the supplied launcher so the UI files and state paths are correct.
