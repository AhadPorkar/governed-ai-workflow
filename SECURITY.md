# Security policy

This release candidate is a synthetic-data portfolio reference. Do not expose the local server publicly or use real customer/payment data. Static expiring bearer identities are demonstration credentials, not production OIDC.

See [the threat model](docs/en/security.md) and [verification boundary](docs/en/testing.md). Do not claim a security audit, regulatory certification or global exactly-once behavior.

Report a reproducible issue through the repository owner's verified private contact route. Never include real secrets or customer records in public issues. Provide the affected version, a synthetic reproduction and expected/actual behavior.
